# OnCalendar v3.0.0 Release

## 📱 APK 다운로드

**파일**: `app-debug-v3.0.0.apk` (4.3 MB)

### 다운로드 방법

#### 방법 1: 직접 다운로드 (추천)
```bash
# 커맨드라인에서
git clone https://github.com/RYUDONGKYUN/Oncalender_v3.git
cd Oncalender_v3/releases
# app-debug-v3.0.0.apk 파일 사용
```

#### 방법 2: GitHub 웹에서
GitHub 저장소 -> Code -> releases 폴더 -> app-debug-v3.0.0.apk 다운로드

#### 방법 3: Raw 다운로드
```
https://raw.githubusercontent.com/RYUDONGKYUN/Oncalender_v3/main/releases/app-debug-v3.0.0.apk
```

---

## 📥 안드로이드에 설치하는 방법

1. **APK 파일을 안드로이드 기기에 복사**
   - USB로 연결하거나
   - 클라우드 스토리지(Google Drive, Dropbox)에서 다운로드

2. **보안 설정 변경**
   - 설정 → 보안 → "알 수 없는 소스" → ON

3. **설치**
   - 파일 관리자에서 app-debug-v3.0.0.apk 찾기
   - 탭해서 설치

## ✨ 주요 기능

- 📅 **캘린더**: 월/주/일 뷰
- ⭐ **기념일**: 양력/음력 자동 변환
- 🎯 **D-day**: 자동 계산
- 🔗 **Google Calendar**: 연동 지원
- 🔔 **알림**: 기념일 알림 설정

---

## 📋 시스템 요구사항

- **최소 Android 버전**: 8.0 (API 26+)
- **저장 공간**: 50MB 이상
